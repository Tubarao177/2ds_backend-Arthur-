# Página Inicial — STAND SHOP

A página inicial apresentará a loja STAND SHOP, especializada em mangás de JoJo's Bizarre Adventure. Terá um banner de boas-vindas, mangás em destaque e um botão para acessar o catálogo.

O visual utilizará roxo, dourado, preto arroxeado e branco, com um menu de navegação para as quatro páginas do site.
